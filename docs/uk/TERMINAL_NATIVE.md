# Нативні компоненти терміналу

Eta пакує помічник терміналу як окремий виконуваний файл ELF у `jniLibs`. Файли мають суфікс `.so`, щоб інсталятор Android розпаковував їх у доступний лише для читання `nativeLibraryDir` і не завантажувався через JNI, а також не запускалися вбудовані помічники Android із каталогу, доступного для запису.

| Програми | ABI | Призначення |
| --- | --- | --- |
| `libeta_pty.so` | arm64-v8a | Створіть справжній псевдотермінал для звичайної оболонки Android і сеансів Linux |
| `libproot_exec.so` | arm64-v8a | Запуск простору користувача Linux під UID програми |
| `libproot_loader.so` | arm64-v8a | Той самий завантажувач ABI, згенерований тією ж компіляцією, що й PRoot |

APK підтримує лише ARM64. `ndk.abiFilters` з `app/build.gradle.kts` обмежує як локальні, так і AAR-залежні нативні бібліотеки, а також лише пакет Debug і Release `arm64-v8a`.

PRoot підтримує лише 64-розрядну rootfs Linux, що відповідає локальній машині, не виконує різнорідні набори інструкцій і не надає прав Root на пристрої. PRoot статично пов’язує talloc і libandroid-shmem і покладається лише на системні бібліотеки Android під час роботи. ELF створено з використанням вирівнювання сторінок 16 KiB.

## Інтерфейс запуску

Параметр PTY — `rows cols -- executable args...`, який використовується для встановлення незалежних сеансів для Root- і звичайних сеансів консолі ідентифікації. Стандартний вихід передає оригінальні кінцеві байти; стандартний вхід передається у кадрах, а заголовок кадру має 1-байтовий тип і 2-байтову довжину в порядку старшого порядку: тип 0 — це кінцевий байт, який записується на псевдотермінал як є; тип 1 — це розмір вікна, а корисне навантаження — це 2 байти рядків і стовпців з порядковим порядком порядкового порядку від 1 до 1000. Після запису ядро ​​надсилає SIGWINCH до групи процесів переднього плану; невідомі типи пропускаються за довжиною. Ctrl-C надсилається як термінальні байти до поточної групи активних процесів через PTY; кінцевий EOF надсилається, коли вхідна труба закрита; група термінальних процесів очищається, коли вікно закривається, батьківський процес завершується або вихідний канал від’єднується. Код виходу зберігає стан дочірнього процесу.

Виклик PRoot повинен встановити `PROOT_LOADER` на поточний `nativeLibraryDir/libproot_loader.so` і `PROOT_TMP_DIR` на приватний тимчасовий каталог, доступний для запису Eta. Відсутні завантажувачі не шукатимуть шляхи встановлення для інших програм. Патчі спільної пам’яті також використовують той самий тимчасовий каталог і не покладаються на глобальний `/tmp`.

## Перебудова

Для збірки потрібні Android NDK, Python 3, GNU make, patch і tar, що відповідають запису `ndk` для `gradle/libs.versions.toml`, що працює на macOS або Linux:

```sh
ANDROID_NDK_HOME=/path/to/android-ndk scripts/build-terminal-native.sh
```

Сценарій спочатку перевіряє `source.properties` NDK і каталог версій, потім використовує фіксований пакет стиснення вихідного коду, включений у синхронізацію APK, і перевіряє SHA-256; лише якщо вихідний код відсутній, він завантажується з адреси фіксованої версії вище. Версія вихідного коду третьої сторони, URL-адреса, зведення та параметри компіляції залежать від сценарію. `ETA_NATIVE_SOURCES` і `ETA_NATIVE_BUILD` можуть вказати кеш вихідного коду та каталог тимчасової збірки відповідно. Журнали компіляції зберігаються в каталозі збірки і не містять файлів конфігурації моделі чи користувача.

Сценарій генерує лише ARM64 ELF і автоматично вводить фактичний сценарій, каталог версій, вихідний код PTY і латки в `app/src/main/assets/native-sources/eta-native-build.tgz`. Цей пакет не можна змінювати вручну. `assets/native-sources` APK також містить оригінальний вихідний код PRoot, talloc і libandroid-shmem; ресурси вихідного коду використовують суфікс `.tgz`, щоб запобігти зміні назви та перевірочного значення пакета ресурсів Android після автоматичного розпакування файлу `.gz`. `assets/licenses` Містить відповідні ліцензії. Розархівуйте пакет збірки, щоб відновити відносний шлях до сховища, а потім передайте каталог, де міститься оригінальний вихідний код, до `ETA_NATIVE_SOURCES`, щоб відновити включені компоненти.
